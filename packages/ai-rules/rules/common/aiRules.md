# AI Rules

## Sources of truth

- Shared Clipboard rules live in `ClipboardHealth/core-utils` under `packages/ai-rules/rules/`.
- Repository-specific instructions live in that repository's optional `OVERLAY.md`.
- `.rules/`, `AGENTS.md`, and `CLAUDE.md` are generated by `sync-ai-rules`; change their source instead of editing them directly.

Put guidance used by multiple repositories in the shared package. Keep only repository-specific policy and gotchas in an overlay.

## Change workflow

- Commit shared rule changes with a Conventional Commit message that begins with `fix:` so Nx publishes a patch release. A `docs:` or `chore:` commit does not release the package.
- After changing an overlay or a shared rule selected by the current repository, run `node --run sync-ai-rules`. Review and commit the source and generated changes together.
- After a shared rule is published, update each affected consumer and regenerate its copies:

  ```bash
  npm install --save-dev @clipboard-health/ai-rules@latest
  node --run sync-ai-rules
  ```
