# AI Rules

`@clipboard-health/ai-rules` is the source of truth for shared AI rules. Consumer repositories copy those rules into `.rules/` when they run their `sync-ai-rules` package script.

## Shared rules

- Do not edit files in a consumer repository's `.rules/` directory. Those copies are generated and will be overwritten by the next sync.
- Edit shared rules in `ClipboardHealth/core-utils`, under `packages/ai-rules/rules/`.
- Commit shared rule changes with a Conventional Commit message that begins with `fix:`. A `docs:` or `chore:` commit will not trigger the required npm package release.
- After the change is merged and the new `@clipboard-health/ai-rules` version is published, pull it into each consumer repository and regenerate the local copies:

  ```bash
  npm install --save-dev @clipboard-health/ai-rules@latest
  node --run sync-ai-rules
  ```

## Repository-specific instructions

- Do not edit `AGENTS.md` or `CLAUDE.md` directly. They are generated by `sync-ai-rules`.
- Put repository-specific agent instructions in `OVERLAY.md` instead.
- After editing `OVERLAY.md`, run `node --run sync-ai-rules`, then review and commit `OVERLAY.md` together with the generated `.rules/`, `.agents/`, `AGENTS.md`, and `CLAUDE.md` changes.
